# Framework de Mensagens

## Identidade de Marca

### Personalidade
| Atributo | Descricao | Nao somos |
|----------|-----------|-----------|
| **Transparente** | Mostramos os dados antes de pedir algo | Opacos ou manipuladores |
| **Acessivel** | Linguagem simples, processo facil | Burocraticos ou complicados |
| **Confiavel** | Dados publicos, empresa registrada | Informais ou duvidosos |
| **Consultivo** | Ajudamos a entender, nao forçamos venda | Agressivos ou insistentes |
| **Eficiente** | Resultado em segundos, processo rapido | Lentos ou enrolados |

### Tom de Voz
- **Formal-amigavel**: Nem coloquial demais nem juridiquês. "Voce" (nao "tu" ou "o senhor")
- **Direto**: Frase curta, informacao clara, sem rodeios
- **Empático**: Reconhecer a situacao do titular sem ser condescendente
- **Educativo**: Explicar termos quando necessario, sem parecer didatico demais

## Palavras e Frases Guia

### USAR
| Palavra/Frase | Contexto |
|--------------|---------|
| "Consulte gratis" | CTA principal |
| "Seu precatorio" | Personalizacao |
| "Em segundos" | Velocidade |
| "Sem compromisso" | Reduzir barreira |
| "Dados publicos" | Transparencia |
| "Antecipar o recebimento" | Em vez de "vender" |
| "Cessao de credito" | Termo tecnico quando necessario |

### EVITAR
| Palavra/Frase | Motivo | Alternativa |
|--------------|--------|------------|
| "Vender seu precatorio" | Conotacao negativa | "Antecipar o recebimento" |
| "Desagio" | Assusta o titular | "Valor para recebimento imediato" |
| "Urgente / Imperdivel" | Pressao comercial | "Quando voce estiver pronto" |
| "Oferta limitada" | Manipulacao | Nao usar |
| "Juridiquês" excessivo | Confunde o titular | Linguagem simples + explicacao |
| "Comprar seu precatorio" | Agressivo | "Antecipar seu credito" |

## Mensagens de Erro e Estados

| Situacao | Mensagem |
|----------|---------|
| Processo nao encontrado | "Nao encontramos este processo na nossa base. Verifique o numero e tente novamente. Dica: use o formato NNNNNNN-NN.NNNN.8.26.NNNN" |
| Processo sem saldo | "Este processo consta na base DEPRE, mas nao possui saldo registrado no momento" |
| Processo suspenso | "Este processo esta temporariamente suspenso. Isso pode ocorrer por diversas razoes juridicas" |
| Token expirado | "O codigo expirou. Clique em 'Reenviar' para receber um novo codigo" |
| Token incorreto | "Codigo incorreto. Verifique e tente novamente. Voce tem mais [N] tentativas" |
| Erro de sistema | "Ops, algo deu errado. Tente novamente em alguns instantes" |
| Limite de tentativas | "Por seguranca, aguarde 30 minutos antes de tentar novamente" |
