# Voz do Cliente

## Contexto

Este documento mapeia as percepcoes, linguagem e expectativas tipicas dos titulares de precatorios com base no perfil do mercado brasileiro de precatorios estaduais de SP. Como o produto ainda nao foi lancado, as informacoes sao baseadas em pesquisa de mercado e comportamento observado no segmento.

## Linguagem do Cliente

### Termos que o Cliente USA
| Termo do Cliente | Termo Tecnico | Nota |
|-----------------|---------------|------|
| "meu precatorio" | Credito judicial / precatorio | Sempre usar "seu precatorio" na comunicacao |
| "quanto vale" | Saldo DEPRE atualizado | Cliente quer numero, nao explicacao |
| "quando vou receber" | Cronograma de pagamento | Maior ansiedade do cliente |
| "vender o precatorio" | Cessao de credito | Termo juridico que precisa ser traduzido |
| "desconto" | Desagio | Nunca usar "desagio" na primeira comunicacao |
| "o governo me deve" | Estado de SP e ente devedor | Validar o sentimento sem prometer prazos |
| "ja espero anos" | Morosidade judiciaria | Empatia fundamental |
| "confio no meu advogado" | Representacao legal | Nao competir com advogado, complementar |

## Temas de Preocupacao

### 1. Transparencia e Confianca
> **Sentimento tipico**: "Quero saber o valor real, sem pegadinha"

- Desconfianca com empresas que pedem dados antes de mostrar qualquer informacao
- Medo de golpe ou fraude (mercado tem historico negativo)
- Valoriza quando ve dados concretos do seu processo
- Compara informacoes com o que o advogado diz

**Implicacao para o produto**: Mostrar saldo ANTES de pedir dados de contato. Ser transparente sobre de onde vem a informacao (DEPRE - dados publicos).

### 2. Urgencia Financeira
> **Sentimento tipico**: "Preciso desse dinheiro agora, nao posso esperar mais"

- Muitos titulares tem necessidade financeira imediata
- Dispostos a aceitar desagio significativo para receber rapido
- Frustracao com a demora do Estado
- Comparam desagio com custo de oportunidade (dividas, investimentos)

**Implicacao para o produto**: Comunicar agilidade no processo de compra. Simular valor liquido que receberiam.

### 3. Complexidade Juridica
> **Sentimento tipico**: "Nao entendo nada disso, so quero meu dinheiro"

- A maioria nao entende os termos juridicos
- Dependem do advogado para tudo relacionado ao processo
- Sentem-se vulneraveis por nao entenderem seus direitos
- Agradecem quando alguem explica de forma simples

**Implicacao para o produto**: Linguagem simples, glossario acessivel, FAQ robusto, conteudo educativo no blog (Fase 2).

### 4. Desconfianca com Intermediarios
> **Sentimento tipico**: "Sera que essa empresa e serio mesmo?"

- Mercado de precatorios tem historico de praticas questionaveis
- Titulares ja foram abordados por telefone/WhatsApp de forma invasiva
- Valorizam empresas que explicam o processo de forma transparente
- Pesquisam reputacao online antes de fechar negocio

**Implicacao para o produto**: Trust signals fortes (CNPJ visivel, endereco fisico, depoimentos reais, explicacao clara do modelo de negocio).

## Objecoes Frequentes

| Objecao | Resposta Estrategica |
|---------|---------------------|
| "Por que preciso dar meu e-mail/telefone?" | "Para enviarmos os detalhes completos do seu precatorio de forma segura" |
| "Vao ficar me ligando?" | "Voce escolhe como quer ser contatado. Sem spam." |
| "O desagio e muito alto" | "Comparamos: receber X agora vs esperar Y anos para Z" |
| "Meu advogado nao recomenda vender" | "Respeitamos. Oferecemos a consulta gratuita independente da decisao" |
| "Como sei que os dados estao certos?" | "Os dados sao extraidos diretamente do sistema DEPRE do Tribunal de SP" |
| "E golpe?" | "Somos empresa registrada [CNPJ]. Dados consultados sao publicos" |

## Expectativas de Experiencia

### O que o cliente ESPERA
1. Ver o valor do precatorio rapidamente (< 10 segundos)
2. Interface simples, sem formularios longos
3. Informacao clara sobre o que vai acontecer em cada etapa
4. Contato humano quando quiser (WhatsApp)
5. Nao ser pressionado a vender

### O que o cliente NAO TOLERA
1. Pedir muitos dados antes de mostrar qualquer resultado
2. Linguagem juridica incompreensivel
3. Ligacoes insistentes e nao solicitadas
4. Falta de clareza sobre custos e desagio
5. Site lento ou que nao funciona no celular
6. Informacoes contradictorias com o que o advogado disse

## Palavras-Chave Emocionais

### Palavras que GERAM CONFIANCA
- Gratuito, transparente, seguro, publico, oficial, simples, rapido
- "Seus dados estao protegidos"
- "Informacao publica do tribunal"
- "Sem compromisso"

### Palavras que GERAM DESCONFIANCA
- Urgente, imperdivel, ultima chance, limitado
- Jargao juridico excessivo
- Promessas de valor sem fundamentacao
- Pressao para decisao imediata
