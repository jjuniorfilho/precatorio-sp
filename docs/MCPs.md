# Servidores Model Context Protocol (MCP)

## Bibliotecas de Contexto
- [Context7](https://context7.com/) - Biblioteca de gerenciamento de contexto

## Análise de Código
- [Repo Prompt](https://repoprompt.com/) - Ferramenta de análise de repositório e prompting

## Gerenciamento de Conhecimento
- **Notion**: Suportado via Connector nativo com alternativa MCP disponível
- **Atlassian Confluence**: Connector nativo disponível, servidor MCP: [mcp-atlassian](https://github.com/sooperset/mcp-atlassian)

## Controle de Versão
- **GitHub**: [github-mcp-server](https://github.com/github/github-mcp-server)
- Outros sistemas de controle de versão possuem alternativas MCP disponíveis

## Gerenciamento de Tarefas
- **Linear**: Suportado via connector nativo
- **Jira**: Disponível através de integrações

## Diretórios de Servidores MCP
- [Glama.ai](https://glama.ai) - Plataforma de descoberta de servidores MCP
- [Awesome MCP Servers](https://github.com/punkpeye/awesome-mcp-servers) - Lista curada de servidores MCP
